Tool logos must comply with the following template:
 - Format: PNG, RGB (GIMP built-in sRGB, 8-bit)
 - Size: 660 pixel width, 238 (if horizontal layout) or 256 pixel (if quadratic layout) height
 - Background: White, with round transparent corners (GIMP -> Filters -> Decor -> Round Corners ... -> Edge radius 66, no drop-off shadow, no background)
